# Mokled - მოკლედ | ქართული ციფრული ხელსაწყოების პორტალი

**Mokled - მოკლედ** არის სწრაფი, უსაფრთხო და უფასო ქართულენოვანი ციფრული ხელსაწყოების პორტალი, რომელიც შექმნილია ყოველდღიური ტექსტური, ფინანსური, საოფისე და მედია ამოცანების მარტივად გადასაჭრელად.

ყველა ხელსაწყო მუშაობს **100%-ით მომხმარებლის ბრაუზერში (Client-Side)** - რეგისტრაციის, სერვერული დანახარჯებისა და ფასიანი API-ების გარეშე. მომხმარებლის ტექსტები, ფინანსური მონაცემები, სურათები და PDF დოკუმენტები არასოდეს იგზავნება გარე სერვერზე.

## პორტალში შემავალი 13 ხელსაწყო

### I. ტექსტური ხელსაწყოები
1. **ქართული ტექსტის კონვერტერი (`georgian-converter.html`)**
   - **ყოფილი პარლამენტის სტანდარტი (`SPParliamentMedium`):** სრული ორმხრივი კონვერტაცია 1997 წლის "Soma Press"-ის `SPParliamentMedium` ფონტის სტანდარტით (`À`-`à` / `U+00C0`-`U+00E0` <-> `ა`-`ჰ` და არქაული `á`-`å` <-> `ჱ`-`ჵ`).
   - **ძველი ქართული ფონტები (`AcadNusx / LitNusx`):** ლათინურ კლავიატურაზე დაფუძნებული 8-ბიტიანი ფონტების კონვერტაცია (`abgdevzTiklmnopJrstufqRySCcZwWxjh`).
   - **უნიკოდი (`UTF-8 / Sylfaen`):** თანამედროვე ქართული მხედრული უნიკოდი Sylfaen ფონტით ვიზუალური ჩვენების რეჟიმით.
   - **ასომთავრული (`ႠႡႢ...`):** ისტორიული ქართული მრგლოვანი დამწერლობის (`U+10A0`-`U+10C5`) ორმხრივი გარდამქმნელი.
   - **ლათინური (ინგლისური):** ლათინური ტრანსლიტერაცია ჭკვიანი დიგრაფებისა (`sh, ch, tch, ts, dz, kh, gh, zh`) და სადავო სიტყვების ვარიანტების მხარდაჭერით.
2. **ქართული ტექსტის გარდაქმნა (`translit.html`)**
   - ლათინური ასოებით აკრეფილი ქართული ტექსტის ქართულ ანბანზე სწრაფი გადაყვანა სადავო სიტყვების ერთი დაწკაპუნებით ჩანაცვლებით.
3. **ტექსტის დამმუშავებელი (`text-tools.html`)**
   - სიტყვების, სიმბოლოების, ხაზებისა და აბზაცების მთვლელი, ზედმეტი გამოტოვებებისა და ცარიელი/დუბლირებული ხაზების მოცილება, მხედრული <-> მთავრული (`U+1C90`-`U+1CBA`) რეგისტრის შეცვლა.

### II. ფინანსური და ბიზნეს კალკულატორები
4. **სესხის და იპოთეკის კალკულატორი (`loan-calculator.html`)**
   - ანუიტეტური და კლებადი გრაფიკების გაანგარიშება.
   - წინსწრებით დაფარვის სიმულაცია (ყოველთვიური დამატებითი თანხა და ერთჯერადი შენატანი) ვადის ან ყოველთვიური შენატანის შემცირების რეჟიმით.
   - დაზოგილი პროცენტისა და შემცირებული თვეების დათვლა, სრული გრაფიკის Excel/CSV ჩამოტვირთვა და ბმულით გაზიარება.
5. **თანხის და რიცხვის სიტყვიერად ჩაწერა (`number-to-words.html`)**
   - ნებისმიერი თანხის (0-დან 999,999,999,999-მდე) გრამატიკულად გამართული ქართული სიტყვიერი ჩაწერა (ლარი/თეთრი, აშშ დოლარი/ცენტი, ევრო/ევროცენტი) ხელშეკრულებებისა და ინვოისების ფორმატით.
6. **ხელფასის კალკულატორი (`salary-calculator.html`)**
   - ორმხრივი გაანგარიშება: ხელზე ასაღებიდან დარიცხულში (`Net -> Gross`) და დარიცხულიდან ხელზე ასაღებში (`Gross -> Net`).
   - საშემოსავლო გადასახადის (20%, 5% საერთაშორისო/IT სტატუსი, 0%) და დაგროვებითი პენსიის (2% + 2%) მხარდაჭერა.
7. **ქართული IBAN შემმოწმებელი და ბანკის ამომცნობი (`iban-validator.html`)**
   - საბანკო ანგარიშის ვალიდაცია საერთაშორისო `ISO 13616 / MOD-97` სტანდარტით, ქართული ბანკისა და SWIFT/BIC კოდის ავტომატური იდენტიფიკაცია.
8. **დღგ-ის კალკულატორი 18% (`vat-calculator.html`)**
   - 18%-იანი დღგ-ის დამატება და დღგ-ის შემცველი თანხიდან დღგ-ის ნაწილის ზუსტი გამოყოფა ფორმულებისა და შუალედური შედეგების ჩვენებით.

### III. მედია, PDF, მონაცემთა და თარიღების ხელსაწყოები
9. **PDF ხელსაწყოების ნაკრები (`pdf-tools.html`)**
   - PDF ფაილების გაერთიანება (Merge), გვერდების ამოღება/დაყოფა (Split/Extract), გვერდების შემობრუნება (Rotate) და სურათების (JPG/PNG) ერთ PDF ფაილად შეკვრა უშუალოდ ბრაუზერში.
10. **სურათის ხელსაწყო (`image-tools.html`)**
    - სურათის შეკუმშვა და პიქსელური ზომების შეცვლა პროპორციების დაცვით (სტანდარტული საბოლოო ფორმატი: JPEG, ასევე WebP და PNG).
11. **QR კოდის გენერატორი (`qr-generator.html`)**
    - სტანდარტული `ISO/IEC 18004` უვადო QR კოდების გენერაცია ბმულისთვის, ტექსტისთვის ან Wi-Fi ქსელისთვის (PNG და ვექტორული SVG ჩამოტვირთვით).
12. **CSV / JSON გარდამქმნელი (`csv-json.html`)**
    - `RFC 4180` სტანდარტის CSV პარსერი, ცხრილური ვიზუალიზაცია და ორმხრივი გარდაქმნა ქართული Unicode-ისა და Excel-ის (`UTF-8 BOM`) მხარდაჭერით.
13. **თარიღების და სამუშაო დღეების კალკულატორი (`date-calculator.html`)**
    - ორ თარიღს შორის კალენდარული და სამუშაო დღეების დათვლა და თარიღზე დღეების დამატება/გამოკლება საქართველოს სახელმწიფო უქმე დღეების გათვალისწინებით.
