# 🇬🇪 Mokled - მოკლედ

Mokled არის ქართულენოვანი ციფრული ხელსაწყოების ვებპორტალი, რომელიც სპეციალურად შექმნილია ყოველდღიური ფინანსური, საბანკო, საოფისე და ტექსტური ამოცანების გასამარტივებლად (სესხისა და ხელფასის კალკულაცია, ქართული კოდირებების კონვერტაცია, PDF და მედია ფაილების დამუშავება).

პორტალი მუშაობს 100%-ით ბრაუზერში (Client-Side) გარე სერვერზე ფაილებისა და მონაცემების გაგზავნის გარეშე, რაც უზრუნველყოფს მაქსიმალურ სისწრაფეს, უსაფრთხოებასა და კონფიდენციალურობას.

🔗 **ვებგვერდი:** [https://mokled.pages.dev/](https://mokled.pages.dev/)

## ✨ ძირითადი ფუნქციონალი
- 💰 **ფინანსები და ბანკინგი:** სესხისა და იპოთეკის კალკულატორი (ანუიტეტური/კლებადი გრაფიკითა და წინსწრებით დაფარვის სიმულაციით), ხელფასის კალკულატორი (Net - Gross), დღგ-ის (18%) კალკულატორი, ქართული IBAN-ის ვალიდაცია (MOD-97) ბანკის ამოცნობით და თანხის სიტყვიერად ჩაწერა.
- 🔤 **ქართული ტექსტი და კოდირება:** ძველი ქართული ფონტებისა და სტანდარტების (AcadNusx, ყოფილი პარლამენტის სტანდარტი, ასომთავრული, უნიკოდი) ორმხრივი კონვერტაცია, ლათინური ტრანსლიტერაცია და ტექსტის სტატისტიკური დამუშავება.
- 📄 **PDF და მედია ხელსაწყოები:** PDF ფაილების გაერთიანება, გვერდების ამოღება/დაყოფა, შემობრუნება და სურათების PDF-ად შეკვრა; სურათების შეკუმშვა და ზომის შეცვლა (JPEG, WebP, PNG); უვადო QR კოდების გენერაცია (PNG / SVG).
- 📊 **მონაცემები და ცნობარები:** საქართველოს საფოსტო ინდექსების სწრაფი საძიებო (თბილისი და რეგიონები), CSV - JSON გარდამქმნელი და კალენდარული/სამუშაო დღეების კალკულატორი საქართველოს ოფიციალური უქმე დღეების გათვალისწინებით.
- 📱 **PWA და კომფორტული UX:** მობილურსა და კომპიუტერზე აპლიკაციად დაყენების მხარდაჭერა (Offline რეჟიმით), მუქი და ნათელი თემა (Dark / Light Mode), რჩეული ხელსაწყოების შენახვა და შედეგების სუფთა PDF ფორმატში ამობეჭდვა.

## 🚀 ტექნოლოგიები
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **PDF & Media Engine:** pdf-lib, HTML5 Canvas API
- **Offline & Storage:** Service Workers (PWA), Web Storage API (localStorage)
- **Testing:** Node.js Test Runner
- **Deployment:** Cloudflare Pages & GitHub
