## 🧰 რას იპოვი Mokled-ზე?

### ფინანსები და საბანკო ოპერაციები
- სესხისა და იპოთეკის კალკულატორი (გრაფიკით, წინსწრებითა და PDF ბეჭდვით)
- ხელფასის კალკულატორი — Net ↔ Gross
- თანხისა და რიცხვის სიტყვიერად ჩაწერა
- ქართული IBAN-ის შემოწმება და ბანკის ამოცნობა
- დღგ-ის კალკულატორი

### ქართული ტექსტი
- ძველი ქართული კოდირებების კონვერტაცია (AcadNusx, პარლამენტის სტანდარტი, უნიკოდი, ასომთავრული)
- ლათინურიდან ქართულად ტრანსლიტერაცია
- ტექსტის ანალიზი, გასუფთავება და რეგისტრის შეცვლა

### დოკუმენტები და მედია
- PDF ფაილების გაერთიანება, დაყოფა, შემობრუნება და სურათების PDF-ად გადაქცევა
- სურათების შეკუმშვა და ზომის შეცვლა
- QR კოდების გენერაცია

### მონაცემები და თარიღები
- საქართველოს საფოსტო ინდექსების სწრაფი საძიებო (თბილისი და რეგიონები)
- CSV ↔ JSON კონვერტაცია
- კალენდარული და სამუშაო დღეების კალკულატორი
